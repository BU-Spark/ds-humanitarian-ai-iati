## Benchmark versions (Deniz)

- v1: 20 questions (`fa26/benchmark/`): 16 with data-derived answers, 4 that test appropriate limits.
- v2: 100 questions (`fa26/benchmark/v2/`), in three disjoint splits (`v2/splits.json`):
  `regression` (20, the v1 questions Q01 to Q20), `development` (40, for inspecting failures and improving the workflow) and
  `heldout` (40, first evaluation before tuning on these questions; freeze the first run). Report the splits separately.
- Scoring (both versions): an answerable question scores 70% value correctness + 30% evidence F1; a clarify / abstain
  question scores its status and reason codes.

## Choosing which models run (05 and 06)

Do not edit `.env` to select models. Each live notebook has a switch in the cell that starts with
`# ---- model switch` (05: cell 8, 06: cell 14), third line:

```python
RUN_MODELS = ["anthropic/claude-sonnet-4-6", "zai/glm-5.3"]   # None = every model registered in .env
```

A name must already be registered in `.env` (`ANTHROPIC_EVAL_MODELS`, `ZAI_MODEL`, ...); an unknown name stops the cell. One-off override without editing the notebook:

```bash
IATI_RUN_MODELS="zai/glm-5.3" jupyter nbconvert --execute ...
```

## Running a benchmark v2 split

```bash
python fa26/benchmark/v2/export_inputs.py ~/Desktop/IATI_Nov/_bundles/v2-development-<date> --split development
IATI_BENCHMARK_BUNDLE=<that dir> python fa26/scripts/smoke_v2_development.py      # templates only, no LLM
IATI_LIVE_EVAL=1 IATI_BENCHMARK_BUNDLE=<that dir> jupyter nbconvert --to notebook --execute --inplace fa26/notebooks/06_hybrid_router_templates_2026-10-22.ipynb
```

Without `IATI_LIVE_EVAL=1` the notebooks run a fake model and no database. On macOS, prefix with `caffeinate -dims` to keep a long run awake.
Tune only on the development split; the first heldout run is frozen (see `fa26/benchmark/v2/README.md`).

## Ask tab (the engine as a module)

`fa26/src/ask.py` packages notebook 06's router as an importable engine (`Engine().ask(question)` returns the
benchmark answer shape plus tool, arguments, query, latency; `evidence_rows()` returns the cited snapshot rows).
Its system prompt differs from notebook 06, and the engine itself has not been scored on the benchmark.
`fa26/ask_app.py` is a minimal Gradio page on top of it:

```bash
conda activate iati
python fa26/ask_app.py                         # http://127.0.0.1:7861, model anthropic/claude-sonnet-4-6
IATI_ASK_MODEL=zai/glm-5.3 python fa26/ask_app.py
IATI_ASK_PORT=7862 python fa26/ask_app.py       # another port
```

## Environment

Use a dedicated conda env so project packages do not collide with other work in `base`:

```bash
conda create -n iati python=3.12 -y && conda activate iati
pip install -r fa26/requirements.txt ipykernel
python -m ipykernel install --user --name iati --display-name "Python (iati)"
```

Select the `Python (iati)` kernel in Cursor / Jupyter.

Rules: notebooks read from `data/raw`, `benchmark/snapshot` or the reference clone and write only to `data/interim` or `data/processed` (both gitignored). Reusable functions move to `src/`. Secrets live in `fa26/.env` (gitignored).
